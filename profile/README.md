### **FEST** - Festival Methodology
AI-native project planning. Goal-oriented project management designed for AI execution.

- **Steps, Not Time** - Traditional PM estimates time. Festival plans steps. AI executes 30-100x faster than humans. Define what needs to happen, not when.
- **Hierarchical Structure** - Festivals contain Phases. Phases contain Sequences. Sequences contain Tasks. Each level has a goal document defining success. Hierarchy that AI can navigate.
- **Autonomy Levels** - Every task marked High, Medium, or Low autonomy. AI knows when to proceed and when to ask. Autonomy without chaos.
- **Quality Gates** - Every implementation sequence ends with testing, code review, and results iteration. Quality enforced by structure.
- **Context Preservation** - Context chains through the festival structure. Goal documents at every level. Multi-day autonomous work without losing context.
- **The Fest CLI** - Create festivals, phases, sequences, tasks. Track progress. Validate structure. All from the command line. JSON-enabled for automation.

`fest create` • `fest status` • `fest next` • `fest validate`
